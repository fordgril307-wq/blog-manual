이웃추가 자동화 설정

공감·댓글과 동시에 이웃신청도 자동으로 진행합니다. 블로그 인기도에 따라 그룹을 나눠 관리할 수 있습니다.

➕ 이웃추가 메시지
방문한 블로그에 이웃신청 시 보낼 메시지

올려주신 포스팅들 정독하고 댓글이랑 공감도 남겨두고 갑니다!ㅎㅎ
앞으로도 새 글 올라오면 1등으로 달려와서 읽고 싶어요. 오늘도 기분 좋은 일 가득한 하루 보내세요!
프리미엄 그룹명 이웃만 최소 댓글수 100 개 이상

프리미엄 그룹 조건 이해하기

방문한 블로그의 두 번째 게시글 댓글 수를 기준으로 그룹을 자동 분류합니다.

⭐ 댓글수 ≥ 100개

→ 프리미엄 그룹("이웃만")에만 이웃추가
그룹이 꽉 차면 이웃추가 자체를 건너뜀 (다른 그룹으로 넣지 않음)

📌 댓글수 < 100개

→ 프리미엄 그룹 제외한 나머지 그룹에 순서대로 이웃추가
그룹이 차면 다음 그룹으로 자동 이동

8

자주 묻는 질문

Q. "invalid session id" 오류가 뜨며 멈춥니다.

크롬이 절전 모드로 전환되어 연결이 끊긴 경우입니다. 프로그램이 자동으로 재연결을 시도하며, 실패 시 텔레그램으로 알림이 옵니다. 재연결 실패 시 크롬 창을 직접 확인해 보세요.

Q. 댓글이 한 블로그에만 계속 달립니다.

네이버에서 임시 차단한 상태입니다. 오른쪽 로그에 ⚠️ 댓글 한도 초과 메시지가 뜨면 자동으로 중단됩니다. 30분~1시간 후 다시 시도하세요.

Q. 이웃추가가 되지 않습니다.

① 이미 이웃인 경우 자동으로 건너뜁니다. ② 모든 그룹이 가득 찬 경우입니다 (네이버 그룹당 최대 인원 초과). ③ 프리미엄 그룹명이 정확히 일치하는지 확인하세요.

Q. 두 번째 실행 시 QR 로그인이 또 나옵니다.

세션 파일(.chrome_session.json)이 삭제되었거나, 크롬이 완전히 종료된 경우입니다. 처음 실행 후 크롬 창을 닫지 않으면 다음 실행 시 자동으로 연결됩니다.

Q. 텔레그램 알림이 오지 않습니다.

① 봇 토큰과 Chat ID가 올바른지 확인하세요. ② 봇에게 먼저 메시지를 보내야 채팅이 활성화됩니다. ③ Chat ID 앞에 -100이 붙는 그룹 채팅인지 확인하세요.

브라우저에서 Chat ID 확인

아래 URL에서 YOUR_BOT_TOKEN 부분을 실제 토큰으로 교체하여 접속합니다.

https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates

JSON 응답에서 "id" 값이 Chat ID입니다.

{"ok":true,"result":[{"message":{"chat":{
"id": 123456789,
"first_name":"홍길동",...}}}]}

대시보드에 입력

TG 봇 토큰 란에 1234567890:ABC... 형태의 토큰을,
TG Chat ID 란에 숫자로 된 Chat ID를 입력합니다.

👥
