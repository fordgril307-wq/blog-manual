준비물 & 설치

필요한 것

💻 소프트웨어

Python 3.9 이상 · Google Chrome 브라우저 · pip 패키지

🔑 API 키 (선택)

Gemini API 키 (AI 댓글 생성용) · 텔레그램 봇 토큰 + Chat ID (원격제어용)

파일 구조

C:\blog\ ├── blog_automation_Gemini.pyw ← 메인 프로그램 ├── chromedriver.exe ← 크롬 드라이버 (선택, 없으면 자동설치) └── chrome_profile\ ← 크롬 로그인 프로필 저장 폴더 (자동생성)

pip 패키지 설치

pip install selenium webdriver-manager requests google-generativeai
📁 chrome_profile 폴더

처음 실행 시 C:\blog\chrome_profile\ 폴더가 자동으로 생성됩니다. 네이버 로그인 정보가 이 폴더에 저장되므로, 삭제하면 로그인이 초기화됩니다.

2

최초 크롬 설정 처음 한 번만

v3.0부터 로그인은 크롬 프로필에 저장됩니다. 최초 1회만 아래 과정을 진행하면, 이후 봇 재시작 시에도 로그인이 유지됩니다.

1
chrome_profile 폴더 생성

탐색기에서 C:\blog\ 폴더 안에 chrome_profile 폴더를 만듭니다.

2
디버그 모드로 크롬 실행

아래 명령어를 Windows 검색 → 실행(Win+R)에 붙여넣고 Enter:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\blog\chrome_profile"

크롬 창이 열리면 성공입니다.

3
네이버 로그인

열린 크롬에서 naver.com으로 이동해 네이버 계정으로 로그인합니다. 로그인 유지 체크박스를 선택하세요.

4
크롬 창은 그대로 두기

이제 봇을 실행하면 이 크롬 창에 자동으로 연결됩니다. 크롬을 닫아도 되지만, 봇 실행 전에 크롬이 먼저 켜져 있어야 합니다. (봇이 자동으로 켜주기도 합니다)

✅ 이후 사용법이 달라집니다

v2.3의 QR 스캔, "로그인 완료" 버튼은 없어졌습니다. 이후 봇 실행 시 크롬이 자동으로 시작되고 저장된 로그인 정보로 바로 시작합니다.

봇 실행
→
크롬 자동시작 (디버그포트 9222)
→
chrome_profile 로그인 로드
→
NID_AUT 확인 → 작업 시작

프로그램 실행 & 기본 화면

1
실행

blog_automation_Gemini.pyw를 더블클릭합니다. 콘솔 창 없이 GUI만 열립니다.

2
API 키 입력

상단 탭에서 API 키를 입력합니다. 이 값은 프로그램 종료 후 저장되지 않습니다 (보안).

  • Gemini API Key: AI 댓글 생성 시 필요
  • Telegram Token / Chat ID: 원격제어 사용 시 필요
3
모드 선택 후 시작

이웃방문 / 검색어 / 이웃추가 모드를 선택하고 옵션을 설정한 뒤 ▶ 시작 버튼을 누릅니다.

⚠️ 로그인 안 된 경우

봇이 네이버에 접속했을 때 NID_AUT 쿠키가 없으면 로그인이 안 된 것입니다. 로그 창에 경고가 뜨고 크롬에서 직접 네이버 로그인하면 30초 이내 자동으로 감지해서 재개됩니다. 텔레그램에도 알림이 옵니다.

FAQ

Q. 크롬이 자동으로 안 켜져요

크롬 설치 경로가 기본 경로가 아닐 수 있습니다. blog_automation_Gemini.pyw 상단의 CHROME_EXE 경로를 본인 환경에 맞게 수정하세요.
기본값: C:\Program Files\Google\Chrome\Application\chrome.exe

Q. "로그인이 필요합니다" 메시지가 계속 나와요

열려 있는 크롬 창에서 naver.com에 접속해 로그인하세요. 봇이 30초마다 로그인 상태를 체크하여 자동으로 재개됩니다. 텔레그램으로도 알림이 옵니다.

Q. 봇을 껐다 켜도 로그인을 다시 해야 하나요?

아니오. chrome_profile 폴더에 로그인 정보가 저장되므로, 봇을 껐다 켜도 로그인이 유지됩니다. 단, 네이버가 보안 이유로 로그아웃시킨 경우 크롬에서 다시 한 번 로그인하면 됩니다.

Q. chromedriver.exe를 별도로 설치해야 하나요?

C:\blog\ 폴더에 chromedriver.exe가 있으면 그것을 사용합니다. 없으면 webdriver-manager가 자동으로 맞는 버전을 다운로드합니다.

Q. 모니터를 꺼도 봇이 돌아가나요?

네. Windows PC 절전(슬립)은 방지하지만 모니터는 꺼도 됩니다. 크롬이 백그라운드 스로틀링되지 않도록 별도 설정이 적용되어 있습니다.

Q. 텔레그램 없이도 쓸 수 있나요?

네. 텔레그램 Token/Chat ID를 비워두면 텔레그램 기능 없이 GUI만으로 동작합니다.

Q. API 키가 저장되지 않는 이유는?

보안을 위해 API 키는 프로그램 실행 중 메모리에만 존재하며, 파일이나 레지스트리에 저장되지 않습니다. 매번 실행 시 입력해야 합니다.

A

부록 A — Gemini API 키 발급

1
Google AI Studio 접속

aistudio.google.com에 구글 계정으로 로그인합니다.

2
API 키 생성

왼쪽 메뉴 → Get API key → Create API key 클릭

3
복사 후 붙여넣기

발급된 키(AIza...로 시작)를 복사해 프로그램 GUI의 Gemini API Key 란에 붙여넣습니다.

💡 무료 한도

Gemini API는 무료 한도 내에서 사용 가능합니다. 한도 초과 시 댓글 생성 기능만 비활성화되고 봇은 계속 동작합니다.

B

부록 B — 텔레그램 봇 설정

봇 생성

1
BotFather 검색

텔레그램 앱에서 @BotFather를 검색 후 채팅 시작

2
/newbot 입력

봇 이름과 username을 설정합니다. username은 반드시 bot으로 끝나야 합니다 (예: myblog_bot)

3
토큰 복사

BotFather가 발급해준 1234567890:AAF... 형식의 토큰을 복사해 GUI의 Telegram Token에 입력

Chat ID 확인

1
봇에게 메시지 보내기

방금 만든 봇을 텔레그램에서 찾아 아무 메시지나 보냅니다 (예: hello)

2
getUpdates API 호출

브라우저 주소창에 아래 URL 입력 (TOKEN 부분 교체):

https://api.telegram.org/botTOKEN/getUpdates
3
Chat ID 확인

JSON 응답에서 "chat":{"id": 123456789 숫자가 Chat ID입니다. GUI의 Chat ID에 입력하세요.

⚠️ 주의사항

봇 토큰을 타인과 공유하지 마세요. 공유된 경우 BotFather에서 /revoke로 즉시 재발급하세요.
