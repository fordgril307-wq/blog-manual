최초 크롬 로그인 설정 처음 한 번만

v3.0은 QR 스캔 없이 크롬 프로필 폴더에 로그인 정보를 영구 저장합니다. 아래 과정은 최초 1회만 진행하면, 이후 봇 재시작 시에도 자동으로 로그인 상태가 유지됩니다.

1
chrome_profile 폴더 만들기

탐색기에서 C:\blog\ 폴더 안에 chrome_profile 폴더를 새로 만듭니다.

📁
이 폴더에 네이버 로그인 쿠키가 저장됩니다. 절대 삭제하지 마세요 — 삭제하면 로그인이 초기화되어 다시 설정해야 합니다.
2
디버그 모드로 크롬 실행

Win+R을 누르고 아래 명령어를 그대로 붙여넣은 뒤 Enter:

"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\blog\chrome_profile"

새 크롬 창이 열립니다. 이 크롬은 일반 크롬과 독립된 별도 프로필입니다.

⚠️
크롬 설치 경로가 다를 경우 (Program Files (x86) 등) 경로를 맞게 수정하세요. 경로를 모르면 바탕화면 크롬 아이콘을 우클릭 → 속성 → 대상에서 확인할 수 있습니다.
3

이웃추가 자동화 설정

공감·댓글과 동시에 이웃신청도 자동으로 진행합니다. 블로그 인기도에 따라 프리미엄 그룹에만 선별 추가할 수 있습니다.

카드 4 — 이웃추가 설정 (ON 상태)
➕ 이웃추가 메시지  ON
방문한 블로그에 이웃신청 시 보낼 메시지:
안녕하세요! 우연히 블로그에 들렀다가 글들이 제 취향이라 이웃 추가 드려요..!
올려주신 포스팅들 정독하고 댓글이랑 공감도 남겨두고 갑니다!ㅎㅎ
프리미엄 그룹명 이웃만
최소 댓글수 100 개 이상
미달 시 이웃추가 스킵 (조건 충족 블로그만 추가)

프리미엄 그룹 조건 이해하기

방문한 블로그의 두 번째 게시글 댓글 수를 기준으로 그룹을 자동 분류합니다.

⭐ 댓글 수 ≥ 100개

→ 프리미엄 그룹("이웃만")에만 이웃추가
그룹이 꽉 차면 이웃추가 자체를 건너뜀

📌 댓글 수 < 100개

→ 프리미엄 그룹 제외 후 나머지 그룹에 순서대로 추가
"스킵" 체크 시: 이웃추가 자체를 건너뜀

그룹명 확인 방법

1
아무 블로그 방문 후 이웃추가 버튼 클릭

이웃추가 팝업이 열립니다.

2
그룹 선택 드롭다운 확인

드롭다운에 보이는 이름 그대로 입력합니다. 예: 이웃만, 새그룹9, 맛집블로거

3
프리미엄 그룹명 란에 정확히 입력

띄어쓰기, 특수문자까지 정확히 일치해야 합니다.

⚠️
이미 이웃인 블로그는 이웃추가 버튼이 다른 텍스트로 표시되어 자동으로 건너뜁니다. 중복 추가 걱정 없이 사용할 수 있습니다.

자주 묻는 질문

Q. 크롬이 자동으로 안 켜져요.

크롬 설치 경로가 기본 경로가 아닐 수 있습니다. blog_automation_Gemini.pyw 상단의 CHROME_EXE 상수 값을 확인하고 실제 경로로 수정하세요. 확인 방법: 바탕화면 크롬 아이콘 우클릭 → 속성 → 대상.

Q. "로그인이 필요합니다" 메시지가 계속 나와요.

열려 있는 크롬에서 naver.com에 접속해 로그인하세요. 봇이 30초마다 NID_AUT 쿠키를 확인해 로그인이 감지되면 자동으로 재개합니다. 텔레그램에도 🔑 알림이 옵니다.

Q. 봇을 껐다 켜도 로그인을 다시 해야 하나요?

아니오. chrome_profile 폴더에 쿠키가 저장되므로 봇을 재시작해도 로그인이 유지됩니다. 네이버가 보안상 로그아웃시킨 경우에만 크롬에서 한 번 더 로그인하면 됩니다.

Q. chromedriver.exe를 직접 설치해야 하나요?

C:\blog\에 chromedriver.exe가 있으면 자동으로 사용합니다. 없으면 webdriver-manager가 현재 크롬 버전에 맞는 드라이버를 인터넷에서 자동 다운로드합니다.

Q. "invalid session id" 오류가 뜨며 멈춥니다.

크롬이 갑자기 종료된 경우입니다. 봇이 자동으로 크롬을 재시작하고 재연결을 시도합니다. 재연결 후에도 NID_AUT를 확인해 로그인 상태를 검증합니다.

Q. 이웃추가가 되지 않아요.

① 이미 이웃인 경우 자동으로 건너뜁니다. ② 이웃 그룹이 꽉 찬 경우입니다. ③ 프리미엄 그룹명이 네이버 실제 그룹명과 띄어쓰기까지 정확히 일치하는지 확인하세요.

Q. 텔레그램 명령어가 반응이 없어요.

① 봇 Token과 Chat ID가 올바른지 확인하세요. ② 봇에게 먼저 메시지를 보내야 채팅이 활성화됩니다. ③ 봇이 실행 중인 상태(▶ 시작 후)에서만 명령을 받습니다.

Q. 모니터를 꺼도 봇이 정상 작동하나요?

네. Windows 슬립은 방지하지만 모니터는 꺼도 됩니다. 크롬 백그라운드 스로틀링 방지 옵션이 적용되어 있어 모니터 OFF 상태에서도 정상 동작합니다.

Q. 댓글이 한 블로그에만 계속 달립니다.

네이버에서 임시 차단한 상태입니다. 로그에 ⚠️ 댓글 한도 초과 메시지가 표시되면 자동으로 해당 동작을 중단합니다. 30분~1시간 후 재시도하세요.

Gemini API 키 발급 방법

Gemini API는 Google AI Studio에서 무료로 발급받을 수 있습니다. AI 댓글 생성 기능을 사용하려면 필요합니다.

1
Google AI Studio 접속

aistudio.google.com에서 구글 계정으로 로그인합니다.

2
"Get API key" 클릭

왼쪽 메뉴 또는 상단의 🔑 버튼을 클릭합니다.

3
"Create API key in new project" 선택
4
생성된 키 복사

AIzaSy...로 시작하는 키를 복사합니다.

5
대시보드 Gemini API Key 입력란에 붙여넣기

저장이나 별도 설정 불필요. 실행할 때마다 입력하면 됩니다.

💡
Gemini API는 월 일정량까지 무료입니다. 일반적인 블로그 자동화 사용량에서는 무료 한도 내에 들어옵니다.
🔒
API 키는 절대 다른 사람과 공유하지 마세요. 프로그램에 입력 후 파일에 저장되지 않으며, 종료 시 사라집니다.

텔레그램 봇 & Chat ID 발급 방법

텔레그램 봇을 만들어 자동화 알림 수신과 원격 제어(/run, /stop 등)를 사용할 수 있습니다.

1단계 — 봇 토큰 발급 (BotFather)

1
텔레그램에서 @BotFather 검색

파란 체크마크(인증) 있는 계정을 선택합니다.

2
/newbot 명령어 입력
/newbot
🤖
Alright, a new bot! How are we going to call it? Please choose a name for your bot.
3
봇 이름 입력 (표시 이름)

예: 내 블로그 알리미

4
봇 username 입력 (_bot으로 끝나야 함)

예: my_blog_alarm_bot
BotFather가 숫자:영문자 형태의 봇 토큰을 발급해 줍니다. 복사해두세요.

2단계 — Chat ID 확인

1
방금 만든 봇과 채팅 시작

봇 링크 클릭 또는 username 검색 후 시작(Start) 버튼 클릭

2
봇에게 아무 메시지나 보내기

안녕 또는 /start 입력

3
브라우저에서 Chat ID 확인
https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates

JSON 응답에서 "id" 값이 Chat ID입니다.

{"ok":true,"result":[{"message":{"chat":{
"id": 123456789,
"first_name":"홍길동",...}}}]}
4
대시보드에 입력

Telegram Bot Token과 Chat ID를 각각 입력합니다.
토큰 형식: 1234567890:ABC... / Chat ID: 숫자

👥
그룹 채팅에서 알림을 받으려면 봇을 그룹에 초대하세요. 그룹 Chat ID는 -100으로 시작하는 음수입니다.
