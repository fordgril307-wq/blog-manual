이웃 방문 모드 설정

내 이웃 피드를 순서대로 방문하며 공감·댓글을 남기는 모드입니다.

항목설명예시
그룹 ID네이버 이웃 그룹 번호. 0은 전체 이웃0, 1, 2...
시작 번호피드 목록에서 시작할 게시글 순번1
끝 번호피드 목록에서 마칠 게시글 순번30, 50, 100

피드 스크롤 동작

6

이웃추가 자동화 설정

공감·댓글과 동시에 이웃신청도 자동으로 진행합니다.

프리미엄 그룹 조건

방문한 블로그의 두 번째 게시글 댓글 수를 기준으로 그룹을 자동 분류합니다.

⭐ 댓글수 ≥ 100개

→ 프리미엄 그룹("이웃만")에만 이웃추가
그룹이 꽉 차면 건너뜀

📌 댓글수 < 100개

→ 나머지 그룹에 순서대로 이웃추가
"스킵" 체크 시: 이웃추가 건너뜀

⚠️
이미 이웃인 블로그는 자동으로 건너뜁니다.

8

자주 묻는 질문

Q. "invalid session id" 오류가 뜨며 멈춥니다.

크롬이 절전 모드로 전환된 경우입니다. 프로그램이 자동으로 재연결을 시도하며, 실패 시 텔레그램으로 알림이 옵니다.

Q. 이웃 방문 모드에서 "댓글 작성자 없음"이 표시됩니다.

봇이 자동으로 피드 화면으로 돌아가 해당 게시글을 다시 찾아 재시도합니다. 재시도 후에도 없으면 건너뜁니다.

Q. 이웃추가가 되지 않습니다.

① 이미 이웃인 경우 자동으로 건너뜁니다. ② 모든 그룹이 가득 찬 경우입니다. ③ 프리미엄 그룹명이 정확히 일치하는지 확인하세요.

Q. 두 번째 실행 시 QR 로그인이 또 나옵니다.

세션 파일이 삭제되었거나 크롬이 완전히 종료된 경우입니다. 처음 실행 후 크롬 창을 닫지 않으면 다음 실행 시 자동으로 연결됩니다.

Q. 텔레그램 알림이 오지 않습니다.

① 봇 토큰과 Chat ID가 올바른지 확인하세요. ② 봇에게 먼저 메시지를 보내야 채팅이 활성화됩니다.

Q. 중지 버튼을 눌렀는데 계속 진행합니다.

중지 신호는 현재 작업이 완료된 직후 반영됩니다. 길어도 한 사이클 내에 멈춥니다. 재시도 루프 중에도 즉시 종료합니다.

📎 부록 B

텔레그램 봇 & Chat ID 발급 방법

1단계 — 봇 토큰 발급 (BotFather)

1
텔레그램에서 @BotFather 검색

파란 체크마크(인증) 있는 계정을 선택합니다.

2
/newbot 명령어 입력 후 이름 설정

username은 영문, _bot으로 끝나야 합니다. BotFather가 봇 토큰을 발급해 줍니다.

2단계 — Chat ID 확인

1
방금 만든 봇과 채팅 시작

봇을 검색해 시작(Start) 후 아무 메시지나 보냅니다.

2
브라우저에서 Chat ID 확인
https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates

JSON 응답에서 "id" 값이 Chat ID입니다.

3
대시보드에 봇 토큰과 Chat ID를 나란히 입력
👥
그룹 채팅의 Chat ID는 -100으로 시작하는 음수입니다.
