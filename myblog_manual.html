자주 묻는 질문

Q. "invalid session id" 오류가 뜨며 멈춥니다.

크롬이 절전 모드로 전환되어 연결이 끊긴 경우입니다. 프로그램이 자동으로 재연결을 시도하며, 실패 시 텔레그램으로 알림이 옵니다.

Q. 댓글이 한 블로그에만 계속 달립니다.

네이버에서 임시 차단한 상태입니다. 로그에 ⚠️ 댓글 한도 초과 메시지가 뜨면 자동으로 중단됩니다. 30분~1시간 후 다시 시도하세요.

Q. 이웃 방문 모드에서 "댓글 작성자 없음"이 표시됩니다.

댓글창을 열었을 때 작성자 정보를 불러오지 못한 경우입니다. 봇이 자동으로 피드 화면으로 돌아가 해당 게시글을 다시 찾아 재시도합니다. 재시도 후에도 없으면 해당 게시글은 건너뜁니다. 로그에 댓글 작성자 없음 → 피드 재이동 후 재시도 메시지가 표시됩니다.

Q. 이웃추가가 되지 않습니다.

① 이미 이웃인 경우 자동으로 건너뜁니다. ② 모든 그룹이 가득 찬 경우입니다. ③ 프리미엄 그룹명이 정확히 일치하는지 확인하세요.

Q. 두 번째 실행 시 QR 로그인이 또 나옵니다.

세션 파일이 삭제되었거나 크롬이 완전히 종료된 경우입니다. 처음 실행 후 크롬 창을 닫지 않으면 다음 실행 시 자동으로 연결됩니다.

Q. 텔레그램 알림이 오지 않습니다.

① 봇 토큰과 Chat ID가 올바른지 확인하세요. ② 봇에게 먼저 메시지를 보내야 채팅이 활성화됩니다. ③ Chat ID 앞에 -100이 붙는 그룹 채팅인지 확인하세요.

Q. 중지 버튼을 눌렀는데 계속 진행합니다.

중지 신호는 현재 작업(댓글 입력 등)이 완료된 직후 반영됩니다. 길어도 한 사이클(몇 초~수십 초) 내에 멈춥니다. 재시도 루프 중에도 중간에 신호를 감지해 즉시 종료합니다.

📎 부록 B

텔레그램 봇 & Chat ID 발급 방법

텔레그램 봇을 만들어 자동화 진행 상황과 완료 보고서를 실시간으로 받을 수 있습니다.

1단계 — 봇 토큰 발급 (BotFather)

1
텔레그램에서 @BotFather 검색

파란 체크마크(인증) 있는 계정을 선택합니다.

2
/newbot 명령어 입력
/newbot
🤖
Alright, a new bot! How are we going to call it?
3
봇 이름 → username 입력

username은 영문, _bot으로 끝나야 합니다. 예: my_blog_alarm_bot
BotFather가 봇 토큰을 발급해 줍니다. 복사해 두세요.

2단계 — Chat ID 확인

1
방금 만든 봇과 채팅 시작

봇을 검색해 시작(Start) 버튼을 누른 뒤 아무 메시지나 보냅니다.

2
브라우저에서 Chat ID 확인
https://api.telegram.org/botYOUR_BOT_TOKEN/getUpdates

JSON 응답에서 "id" 값이 Chat ID입니다.

3
대시보드에 입력

봇 토큰과 Chat ID를 같은 줄에 나란히 입력합니다.

👥
그룹 채팅의 Chat ID는 -100으로 시작하는 음수입니다.
📎 부록 C

크롬 영구 로그인 설정 방법

봇이 실행될 때마다 QR 로그인을 반복하지 않도록, 로그인 세션을 영구 저장하는 방법입니다. 한 번만 설정하면 이후 실행 시 자동으로 로그인된 상태로 시작됩니다.

⚠️
이 설정은 최초 1회만 필요합니다. 설정 후에는 크롬을 닫아도 로그인이 유지됩니다.

준비사항 체크리스트

항목내용확인
크롬 디버깅 포트 설정 크롬을 --remote-debugging-port=9222 옵션으로 실행해야 봇이 붙을 수 있습니다 필수
전용 크롬 프로파일 폴더 기존 크롬과 별도의 프로파일 폴더를 사용해야 충돌이 없습니다 필수
네이버 로그인 유지 체크 로그인 시 "로그인 상태 유지" 옵션 체크 권장
크롬 바로가기 생성 매번 명령어 입력 없이 더블클릭으로 실행하기 위해 권장

1단계 — 전용 크롬 바로가기 만들기 (Windows)

1
바탕화면에 크롬 바로가기 생성

바탕화면 빈 곳에서 우클릭 → 새로 만들기 → 바로 가기를 선택합니다.

2
아래 경로를 항목 위치에 입력
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\ChromeBot"

• --remote-debugging-port=9222 — 봇이 크롬에 연결하는 포트
• --user-data-dir="C:\ChromeBot" — 전용 프로파일 저장 폴더 (자동 생성됨)

3
바로가기 이름 지정 후 완료

예: 블로그봇 크롬 으로 저장합니다. 이제 이 바로가기로만 크롬을 실행하세요.

2단계 — 최초 로그인 (1회만)

1
위에서 만든 바로가기로 크롬 실행

처음 실행 시 빈 크롬 창이 열립니다. (기존 크롬과 다른 창)

2
네이버에 직접 로그인

주소창에 naver.com 입력 → 로그인 → "로그인 상태 유지" 체크 후 로그인합니다.

📌
QR 로그인 또는 아이디/비밀번호 로그인 모두 가능합니다. 이때 로그인 상태 유지를 반드시 체크하세요.
3
크롬 창을 열어둔 채로 봇 실행

이 크롬 창을 닫지 말고 봇 프로그램을 실행하면, 봇이 자동으로 이 창에 붙어서 로그인된 상태로 시작합니다.

⚠️
봇 실행 중에는 이 크롬 창을 직접 조작하지 마세요. 봇이 제어 중인 창입니다.

3단계 — 이후 사용 (매번)

① 블로그봇 크롬 바로가기 실행

바탕화면의 전용 바로가기를 더블클릭합니다. 이미 네이버 로그인이 되어 있습니다.

② 봇 프로그램 실행

봇이 열려 있는 크롬에 자동으로 연결됩니다. QR 스캔 없이 바로 시작합니다.

✅
크롬을 닫았다가 다시 켜도 로그인이 유지됩니다. 단, 반드시 전용 바로가기(디버깅 포트 포함)로 실행해야 봇이 연결됩니다.

Mac / 폴더 경로가 다른 경우

OS크롬 실행 명령어
Windows "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\ChromeBot"
Mac /Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222 --user-data-dir="/Users/나/ChromeBot"

※ C:\ChromeBot 또는 /Users/나/ChromeBot 폴더는 처음 실행 시 자동으로 만들어집니다.
